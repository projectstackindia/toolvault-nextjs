# 🚀 ToolVault — All-in-One Smart Tools Platform

A modern, fast, and fully frontend-based utility suite. No backend, no database, no authentication — just pure client-side functionality. All tools run instantly in your browser and respect your privacy.

## ✨ Features

- **10+ Powerful Tools** – from Age Calculator to Random Quote Generator
- **Instant Results** – no page reload, no waiting
- **100% Private** – all data stays on your device (no servers, no tracking)
- **Beautiful Glassmorphism UI** – modern, clean, and responsive
- **LocalStorage Support** – notes are saved automatically
- **Copy to Clipboard** – every result can be copied with one click

## 🛠️ Included Tools

| Tool | Description |
|------|-------------|
| 📅 Age Calculator | Calculate exact age in years, months, days (DD-MM-YYYY format) |
| ⚖️ BMI Calculator | Compute Body Mass Index and health category |
| 📝 Word Counter | Count words, characters (with/without spaces), and sentences |
| 🔐 Password Generator | Generate strong random passwords (uppercase, lowercase, numbers, symbols) |
| 🔤 Text Case Converter | Transform text to UPPERCASE, lowercase, Title Case, or Sentence case |
| 🏷️ Discount Calculator | Calculate savings and final price after discount |
| ⏱️ Date Difference | Find duration between two dates (days, weeks, months, years) |
| 🔢 Number System Converter | Convert between Binary, Octal, Decimal, Hexadecimal (custom dropdowns) |
| 📓 Notes App | Save private notes (persisted in browser's localStorage) |
| 💬 Random Quote Generator | Get inspired by famous quotes with copy option |

## 🧩 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS + custom glassmorphism effects
- **Language**: TypeScript
- **State Management**: React Hooks (useState, useEffect)
- **Storage**: localStorage (only for Notes App)

## 🚀 Getting Started

1. Make sure you have Node.js 18+ installed.
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open http://localhost:3000 in your browser.
5. Build for production: `npm run build` then `npm start`

## 🎨 Design Highlights

- **Glassmorphism** – backdrop blur, semi-transparent backgrounds, subtle borders
- **Responsive** – works on mobile, tablet, and desktop
- **Interactive** – hover scaling, transitions, custom SVG arrows
- **Consistent** – all tools share the same layout and styling patterns

## 🔒 Privacy & Security

- No external API calls
- No cookies or tracking scripts
- All logic runs client-side
- Notes are stored only in your browser's localStorage
